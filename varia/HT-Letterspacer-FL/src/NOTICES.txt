HT Letterspacer for FontLab 9 — gateway release 1.0.0

This is a FontLab adapter for Huerta Tipografica's HT Letterspacer. It is not
a replacement Glyphs plugin and does not install anything into Glyphs itself.
The original project and its authors are credited at:
https://github.com/huertatipografica/HTLetterspacer

Gateway source and installer: GNU General Public License, version 3.
See LICENSE. Corresponding source, including the build tools, accompanies
every customer ZIP as HT-Letterspacer-FontLab-1.0.0-source.zip. The .vfpy also
contains its runtime source and a complete corresponding-source ZIP, including
the installer and build tools.

Original HTLetterspacer: the installer downloads the unchanged repository
at commit b4ad60bd36284f87edf9f2145d38bbf87b2e9909. It retains the original
source ZIP, LICENSE, AUTHORS.txt and CONTRIBUTORS.txt in the installed
runtime. GitHub is used only for this pinned download. No fonts, settings,
account information or telemetry are uploaded by this installer.

GlyphsInfo classification XML: copyright (c) 2016 Georg Seifert, MIT license.
Distributed via glyphsLib 6.16.2. The complete notice is retained in
htls_fontlab/data/GlyphData_LICENSE.

CA certificate bundle: certifi 2026.10.23, Mozilla Public License 2.0.
See CERTIFI-LICENSE (installer/CERTIFI-LICENSE in the source package).
The CA bundle is used by the managed-deployment CLI. The native installer uses
Qt's system trust store. TLS checking is never disabled.
