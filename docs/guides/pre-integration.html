    Historical integration guide

    This complete retained guide describes an earlier source and dependency cohort. Its native results, commands and archive paths are historical; use the current installation and menu pages for this source. No historical acceptance is renewed by this documentation build.

    Current source requirements

    Current scripts require fontlab-fontlabapp>=1.2.0 because they import the domain module layout introduced in App 1.2.0. Use matching 1.2.0 package-set artifacts and the current README installation and testing instructions. Native qualification remains separate. The per-feature version labels, old setup recipes and release acceptance records below are historical; they are not installation instructions or acceptance for the current menu.

    fontlab-python-scriptmix

    Small and useful scripts for FontLab

    Canvas reporters

    Reports contains Sidebearing Direction Marker. Duplicate Anchor Rings moved to fontlab-python-plugmix as a Reporter plugin. Requires fontlab-fontlabapp 0.2.23 or newer and fontlab-fly. Open a Glyph window, run the script, then choose the direction. Disable or Close removes its overlay. Reopen after switching font, master or Glyph window. The panel changes no font data.

    These are foreground adaptations across tools. Direction and handle size are explicit; Glyphs background ordering and automatic tool suppression are absent. Native geometry, pixels, clipping, lifecycle and preservation checks pass. The complete prior68 regression passes after the measured guide-date correction. App v0.2.23 and Scriptmix v1.0.18 pass downloaded-tag native and asset verification. additional-tools.json records their independent provenance and evidence. They do not increase the130sample migration denominator or its68accepted rows.

    Installation and Reports

    Copy the contents of Scripts into your FontLab Scripts menu folder. Keep the category subfolders, such as Reports and Font Info; FontLab supports one folder level. Use FontLab 9's Python 3.11 with fontlab-fly and fontlab-fontlabapp (including scripting) available in its Python environment. No third-party UI package is needed.

    Open a font, then run Empty Glyphs, Open Contours or Font Overview from Reports. The dialogs are modeless: edit the font and Rescan/Refresh when needed. Empty Glyphs can hide intentional whitespace. Select chosen rows, or leave rows unselected to select all results. Selection refuses results after changing the current font; rescan first. Reports read all masters without changing geometry. Closing a report disconnects its signals. Re-running replaces its old window. Close also destroys the native dialog after its event finishes. All eight reports share this lifecycle code through fly.ap.core.scripting.

    Sources stay archived until full reconciliation; migration.json records exact Apache-2.0 provenance/hashes and WORK.md retains native acceptance receipts.

    A failed scan or table refresh invalidates selection until a complete rescan succeeds. Partial results are cleared; explicit selection calls also refuse them.

    Reports: second migration batch

    Live Glyph Info follows the selected glyph twice a second, with per-master metrics, outline/component/anchor counts and Pause. Glyph Table CSV offers all or selected glyphs, sortable widths/counts, Copy CSV and a modeless UTF-8 CSV save chooser. Label Statistics shows mark colours and suffix groups; Add to selection preserves the current selection. Nodes Near Zones checks transformed on-curve nodes across masters with selection scope and a 1–30 unit tolerance. Unicode Coverage includes untouched-block filtering, progress bars and block selection. Explicit selection is bound to the font that supplied the rows.

    All five retain the original interactions and pass their original native scenarios, including the live timer and owned Close, on FontLab9.0.9784.

    Font Info tools

    The Font Info menu includes Glyph Order Preview and Export, Master Metrics Table, Names and Credits, Unicode Ranges and Codepages, Bump Font Version and Calculate Vertical Metrics. All original controls, embedded Unicode data, assessment notices, export, previews and the metric diagram are retained.

    Names changes style on the original current master and credits font-wide. Master Metrics edits every displayed master. Version bump optionally appends a dated note to every master. Vertical Metrics defaults to hhea and Win; Typo is optional because it also moves FontLab's own ascender/descender lines. Its bounds are captured on open; reopen after outline changes. Glyph Order exports UTF-8 text without reordering the font; Unicode coverage reports without editing it.

    Apply uses the last complete preview, refuses closed/switched fonts and changed source values, validates the entire plan before writes, preserves the active master and rolls back attempted fields on failure. Failed previews disable Apply. Names and current-master vertical metrics also refuse a master switch. No-op plans add no history. The shared metadata helper notifies only the package and its master container. Fontport's existing history protocol may add an extra no-op Undo checkpoint. All six pass their original native scenarios on FontLab 9.0.9784. All four editors pass one-step Undo, Redo, saved metadata reopening and complete font-data preservation. Native tests also verify no-op history and switched-font refusal. Shared panels load lazily through Fontlabapp; each tool keeps its own controls and actions. Glyph Order uses an owned modeless save chooser and reports the exported count and filename.

    Feature tools

    Features contains Alternate Preview, Build Suffix Substitution, Classes Browser, Feature Code Viewer, Ligature Finder and Suffix Report. They preserve the original master proof, filters, selection, literal search/highlights and Copy controls. Proof rows use one outline scale per master and wrap large families.

    Build previews actual suffix substitutions and appends them to the requested feature, retaining prefix, ordered unrelated features and classes. Apply binds to the original font, complete feature source and referenced glyphs. It uses Fontport's existing ordered writer and Undo safety checks through App, skips no-ops and reports unexpected native failures as possibly partial. Install App's optional fontedit dependency for Build and Feature Code Viewer; native fontpr must be available. The viewer reads exact stored prefix/ordered blocks, rather than native iterator values or synthesized class-prefix text. It does not compile features: test the result in FontLab's Features panel.

    These six tools pass their native scenarios and actual Close destruction. The builder passes complete feature-only saved deltas, one-step Undo, Redo and reopening. All20migrated tools pass183workflow checks together on FontLab9.0.9784. Clipboard operations remain host-free tested; native checks inspect the actual suffix preview under the owner's clipboard exclusion. No export chooser is needed: these six originals provide Copy, not file export.

    Host-free distribution checks

    Run with Python 3.11 through uv and an explicit current App requirement: 

    SCRIPTMIX_APP_REQUIREMENT=/path/to/current-app.whl ./test.sh
# Proof needs App0.2.10 helpers; build the current checkout:
uv build /path/to/app --out-dir /path/to/dist
SCRIPTMIX_APP_REQUIREMENT=/path/to/dist/current-app.whl ./test.sh

    Cached uv requirements permit offline wheel tests. Sources resolve without native binaries; development may set SCRIPTMIX_APP_SOURCE=/path/to/app/src/fontlabapp alongside the explicit dependency. Missing helpers fail the run.

    Every default run checks all 54 destination hashes, exact menu paths/depth, Python 3.11 syntax and provenance metadata. It does not audit absent originals. To additionally check every original source hash, provide the workspace root containing externally restored historical fontlab-python-examples paths (see the archive identities in NOTICE):

    SCRIPTMIX_APP_REQUIREMENT=/path/to/current-app.whl ./test.sh --original-source-root /path/to/workspace

    An absent external source folder skips only its optional byte audit. A present archive with missing files or mismatched hashes fails. Historical source hashes remain recorded; this guide describes the earlier release layout.

    Names inspection and selection tools

    Names contains Case Pairs, Character Info, Character Set Compare, Glyph Finder and Select by Mark. Keep counterparts, add mark groups, use language presets, search names/globs/Unicode and copy characters or missing sets. Character Info follows selection every 500 ms and paints the current master outline beside system text; closing stops the timer. No Pause control existed in this original.

    These five use App0.2.6's lazy panel, tables, signals and selection helpers. Complete refreshes bind actions to their original font. Switched/closed fonts, missing names and failed scans refuse selection before clearing it. Native workflows, full saved-font/history invariance and owned Close pass. The live specimen fits tall accents/overhangs; clipboard has host-free proof only.

    Read-only Kerning tools

    Kerning contains Classes Browser, Compare Masters, Pair List Browser, Missing Pairs and Text Preview. Browse class members and all-master values, flag missing, sign-changing or jumping pairs, filter exact sides with =T, sort numerically, and export the actual shown order to UTF-8 CSV through an owned modeless chooser. Missing Pairs expands characters, names and @classes and retains Copy list. Text Preview draws actual transformed outlines and advances with native effective kerning, master/size controls, Kerning and Show values. Oversized proof fits its complete ink, including accents and overhangs. No font data is written.

    These require App0.2.7 helpers. Native workflows, complete saved-font/history invariance, actual save-dialog export, live proof and Close destruction pass. Exceptions Finder and Pairs From Text are editing tools described below.

    Kerning editors

    Copy Between Masters retains replace/missing/matching modes and checked targets. Pair Editor edits every master cell, adds either-side partners and deletes with blank cells; invalid text is ignored while other valid cells remain staged. Scale Values, Round Values and Remove Small Pairs retain current/all-master scope, zero options, sorted previews and exact original rounding rules.

    These tools require App0.2.8 helpers from a tag/current built wheel or the source override above; index publication is separate. The writer validates every master, uses one native history batch, preserves explicit zero/absence and refuses fractional source history and final values outside +/-2*positive finite UPM. Apply refuses changed pairs/classes/masters or a switched/closed font; Refresh recovers failed reads. Close shares owned cleanup. Allfive pass original native scenarios, complete saved-font deltas, firstUndo/Redo, reopen, safety andClose (receipts in WORK.md). The two additional editors need App0.2.9 helpers from that same wheel/source recipe. Exceptions Finder lists broader class overrides, offers Tick redundant/Untick all and removes exactly ticked rows. Pairs From Text resolves characters and /name words into unique adjacent pairs; Set/Add uses displayed effective kerning on current/all masters, marking explicit glyph values versus inherited class values. Both pass native controls, full-font Undo/Redo/reopen andClose. All37tools pass 301workflow/99preservation/94safety checks; all37mappings pass.
