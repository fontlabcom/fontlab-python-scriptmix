# FontLab Scriptmix

Scriptmix contains small scripts for FontLab's Scripts menu. Use the reports to
inspect an open font. Use the editors to preview a change before you apply it.
Canvas reporters draw on the Glyph window without changing the font.

Start with [installation](install.md). The [script catalogue](scripts/index.md)
contains the purpose, full usage description, source hash and immutable source link for every current menu script.

The [working with scripts](use.md) page explains font selection, previews and
window cleanup. The [documentation guide](contribute.md) explains how to rebuild
this site from the checked-out source.

## Catalogue and acceptance scope

The practical catalogue contains all 261 current menus. The broader classified offline smoke covers 350 scripts; that classification is separate from native acceptance. The original native denominator remains 130, with only the historically qualified 68 smokes retained. New documentation renews none of those native results. Read the full [porting backlog](backlog.md), [historical integration guide](guides/pre-integration.md) and [Text Holder guide](guides/text-holder.md).
